    DNS filter

    Every DNS lookup is sent to the controller at the first switch it enters. The controller checks the domain, then either lets the lookup through to the router or answers it itself with the blocked page.

        DHCP to router

        When a host asks for an address, its broadcast is caught at the first switch, readdressed to the router's MAC, and sent up one path to the router. No other host receives it.
